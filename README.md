# SynRDM: LiDAR-based road markings synthetic dataset
This is the official repository of the SynRDM dataset. SynRDM is a large-scale synthetic 
LiDAR sequential point cloud dataset with cluster-wise annotations for road markings. 
It is designed to facilitate research in LiDAR-based road marking detection and segmentation, 
which are crucial for autonomous driving and advanced driver-assistance systems (ADAS).
